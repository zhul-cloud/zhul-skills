# zhul-skills · 烛龙外贸 AI 技能库

> 用 AI 重构外贸全链路——从获客、背调、沟通、谈单、复盘到成交的完整 Skill 体系。

## 安装

```bash
git clone https://github.com/your-username/zhul-skills.git
cd zhul-skills
chmod +x install.sh
./install.sh
```

安装采用 symlink 方式，`git pull` 后无需重新安装，自动生效。

## 使用

在 Claude Code 中输入斜杠命令即可调用：

```
/烛龙解读客户   客户英文消息
/烛龙英文回复   我想说的中文意思
/烛龙客户背调   公司名或询盘内容
/烛龙公海跟进   粘贴或指定客户背调报告
/烛龙话术复盘   粘贴对话记录
/烛龙催单跟进   描述当前跟进卡点（报价后未回应/PI已发未回应/客户拖延）
```

### 07 · 发品自动化

外贸独立站/阿里国际站的商品发布自动化，为具体项目服务（当前主要给 `llm-wiki` 项目用，依赖其 `wiki/products/`、`outbox/` 等项目内目录结构，需在该项目工作目录下调用）。

| Skill | 功能 | 状态 |
|-------|------|------|
| publish-to-website | 把归档完的型号营销内容自动发布成独立站正式商品页（生成内容包、同步图片视频、构建部署、更新索引追踪表） | ✅ 可用 |
| alibaba-publish | 阿里国际站每日自动发品——选品/定价/打包素材/登记队列/回收结果回写，实际发品由 Accio Work 侧 `alibaba-product-publish` 官方skill执行，两边通过磁盘 `outbox/` 目录传递信号 | ✅ 可用（2026-09-14 首个测试型号入队，等待Accio侧验证结果回写） |
| gsc-submit | 自动向 Google Search Console 提交独立站待索引URL | ✅ 可用 |
| gsc-confirm | 巡检已提交URL的实际收录状态，更新追踪表 | ✅ 可用 |

### 08 · 采购

| Skill | 功能 | 状态 |

| 烛龙AI询价 | 读取 ERP 询价任务 → 在各平台同时找店询价、跟进回复 → 在任务页面填报价并提交回价（一次一个任务；一期只启用淘宝，1688/闲鱼待实跑验证） | ✅ 可用（v1.1.0） |

## 设计理念

基于 Andrew Ng 的 AI 转型框架：
- **从高频任务开始**：先自动化每天做100次的事
- **AI 原生设计**：不是在旧流程里加工具，而是重新设计流程
- **闭环驱动进化**：每次复盘的发现 → 更新话术库 → 所有人受益
