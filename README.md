# zhul-skills · 烛龙外贸 AI 技能库

> 用 AI 重构外贸全链路——从获客、背调、沟通、谈单、复盘到成交的完整 Skill 体系。

## 安装

先安装 Git，再把本库克隆到准备长期保留的目录。安装脚本把技能目录链接到 AI 的个人技能目录，无需逐个复制。

### Windows（PowerShell）

```powershell
git clone https://github.com/zhul-cloud/zhul-skills.git
cd zhul-skills
.\install.ps1 -Agent both
```

### macOS / Linux

```bash
git clone https://github.com/zhul-cloud/zhul-skills.git
cd zhul-skills
chmod +x install.sh
./install.sh --agent both
```

上面的命令把全部技能安装到 **Claude Code 和 Codex**。只用其中一个客户端，或只装一个技能时，在仓库目录选用：

| 安装范围 | Windows PowerShell | macOS / Linux |
|---|---|---|
| 全部技能 → 两个 AI | `.\install.ps1 -Agent both` | `./install.sh --agent both` |
| 全部技能 → Claude Code | `.\install.ps1 -Agent claude` | `./install.sh --agent claude` |
| 全部技能 → Codex | `.\install.ps1 -Agent codex` | `./install.sh --agent codex` |
| 只装询价 → 两个 AI | `.\install.ps1 -Agent both -Skill "烛龙智能询价"` | `./install.sh --agent both --skill "烛龙智能询价"` |

只装询价到一个客户端时，把最后一行的 `both` 换成 `claude` 或 `codex`。其他技能用各自文件夹名指定；完整参数见 `.\install.ps1 -Help` 或 `./install.sh --help`。为兼容旧用法，省略 Agent 参数时仍默认安装到 Claude Code。

安装脚本会输出每个技能的完整链接路径。Windows 使用目录 Junction，macOS/Linux 使用软链接。安装后保留仓库原位置，不要删除它。

已有旧的复制安装、不同目标链接，或 Codex 旧技能目录（Windows：`%USERPROFILE%\.codex\skills\`；macOS/Linux：`$HOME/.codex/skills/`）中的同一技能时，先把旧副本或链接移到所有技能搜索目录以外备份，再运行安装脚本；脚本不删除或覆盖冲突目录。询价旧名迁移另见[手册安装说明](08-采购/烛龙智能询价/使用手册.md#3-安装)。

若 PowerShell 提示禁止运行 `.ps1` 脚本，可在**当前窗口**执行 `Set-ExecutionPolicy -Scope Process -ExecutionPolicy RemoteSigned` 后重试；窗口关闭后失效。电脑受组织策略管理时，联系管理员处理。

## 使用

安装后新开会话。Claude Code 使用 `/技能名`；Codex（桌面 / CLI / IDE）使用 `$技能名`。以下两组示例一一对应：

**Claude Code**

```text
/烛龙解读客户 客户英文消息
/烛龙英文回复 我想说的中文意思
/烛龙客户背调 公司名或询盘内容
/烛龙公海跟进 粘贴或指定客户背调报告
/烛龙话术复盘 粘贴对话记录
/烛龙催单跟进 描述当前跟进卡点（报价后未回应/PI已发未回应/客户拖延）
```

**Codex（桌面 / CLI / IDE）**

```text
$烛龙解读客户 客户英文消息
$烛龙英文回复 我想说的中文意思
$烛龙客户背调 公司名或询盘内容
$烛龙公海跟进 粘贴或指定客户背调报告
$烛龙话术复盘 粘贴对话记录
$烛龙催单跟进 描述当前跟进卡点（报价后未回应/PI已发未回应/客户拖延）
```

## 更新

先结束正在使用这些技能的任务，再回到最初克隆的仓库目录：

```bash
git pull --ff-only
```

链接安装会随仓库文件更新；新开 AI 会话后确认实际版本。新增技能时重新运行安装脚本；搬动仓库时，先把指向旧位置的链接移出技能搜索目录，再重新安装。拉取提示本地修改或分支冲突时，联系维护者处理，不强制覆盖。询价技能的本机记录保留，详情见[更新说明](08-采购/烛龙智能询价/使用手册.md#7-更新)。

## 设计理念

基于 Andrew Ng 的 AI 转型框架：

- **从高频任务开始**：先自动化每天做100次的事
- **AI 原生设计**：不是在旧流程里加工具，而是重新设计流程
- **闭环驱动进化**：每次复盘的发现 → 更新话术库 → 所有人受益
