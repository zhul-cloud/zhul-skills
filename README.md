# zhul-skills · 烛龙外贸 AI 技能库

> 用 AI 重构外贸全链路——从获客、背调、沟通、谈单、复盘到成交的完整 Skill 体系。

## 安装

```bash
git clone https://github.com/your-username/zhul-skills.git
cd zhul-skills
chmod +x install.sh
./install.sh
```

安装采用 symlink 方式，`git pull` 后无需重新安装，自动生效。

## 使用

在 Claude Code 中输入斜杠命令即可调用：

```
/烛龙解读客户   客户英文消息
/烛龙英文回复   我想说的中文意思
/烛龙客户背调   公司名或询盘内容
/烛龙话术复盘   粘贴对话记录
```

## 设计理念

基于 Andrew Ng 的 AI 转型框架：
- **从高频任务开始**：先自动化每天做100次的事
- **AI 原生设计**：不是在旧流程里加工具，而是重新设计流程
- **闭环驱动进化**：每次复盘的发现 → 更新话术库 → 所有人受益
