# 烛龙智能询价 · 使用手册

适用版本：2.7.6。版本变化见 [CHANGELOG.md](CHANGELOG.md)。

## 1 能做什么

把 ERP「我的询价」任务交给 AI，在淘宝、1688 找店询价、跟进回复，并整理报价回填 ERP。支持指定任务或逐个处理全部待处理任务。

**默认会真实向商家发送消息，并提交 ERP 回价。**

## 2 使用前准备

- 已安装 Git、Node.js 18 或以上，以及已登录的 Claude Code 或 Codex。
- 已安装 BrowserOS neo，并将 MCP 连接到当前 AI 客户端。
- 在 BrowserOS 中登录公司 ERP 采购账号、淘宝及1688买家账号。密码和文字/短信验证码由你处理；已有登录直接复用。

开始时 AI 会检查连接，需要配对、权限或登录协助时按提示处理，无需反复重启。

### 配置

在聊天中查看或修改配置，不会启动询价：

| 操作 | Claude Code | Codex |
|---|---|---|
| 查看配置 | `/烛龙智能询价 settings` | `$烛龙智能询价 settings` |
| 修改指定项 | `/烛龙智能询价 settings 把首次人工回复等待时间改为 8 分钟` | `$烛龙智能询价 settings 把首次人工回复等待时间改为 8 分钟` |
| 恢复指定项 | `/烛龙智能询价 settings reset firstHumanReplyMinutes` | `$烛龙智能询价 settings reset firstHumanReplyMinutes` |
| 恢复一组配置 | `/烛龙智能询价 settings reset shopsPerLink` | `$烛龙智能询价 settings reset shopsPerLink` |
| 恢复全部默认 | `/烛龙智能询价 settings reset --all` | `$烛龙智能询价 settings reset --all` |

同一电脑、同一系统用户的两个客户端共用个人设置，更新技能会保留它。修改前先停止正在运行的询价并等 AI 确认。恢复默认不删除 ERP 地址或业务记录。各项含义和配置规则见[配置说明](references/settings.md)。

## 3 安装

先按[技能库安装说明](../../README.md#安装)安装 Git、克隆仓库；已有仓库进入原目录。以下命令在仓库目录执行，只装询价技能，同时供两个客户端使用。

**Windows PowerShell**

```powershell
.\install.ps1 -Agent both -Skill "烛龙智能询价"
```

**macOS / Linux 终端**

```bash
chmod +x install.sh
./install.sh --agent both --skill "烛龙智能询价"
```

只用一个客户端时，将 `both` 改为 `claude` 或 `codex`。安装后保留仓库原位置；安装目录、旧副本或链接冲突处理见[技能库安装说明](../../README.md#安装)。

如装过旧名 `烛龙AI询价` 或 `zhul-trade-sourcing`，将旧副本或链接移出所有技能搜索目录后按新名安装，保留个人数据；通用目录位置和冲突处理仍见上述安装说明。

## 4 开始使用

安装后新开 AI 会话，先按第5节确认版本和目录，再选择任务范围：

| 客户端 | 全部待处理任务 | 只做指定任务 |
|---|---|---|
| Claude Code | `/烛龙智能询价 start` | `/烛龙智能询价 IQ20261016001A` |
| Codex（桌面 / CLI / IDE） | `$烛龙智能询价 start` | `$烛龙智能询价 IQ20261016001A` |

明确执行询价时，`start`、「询价」「开始」「处理」均为逐个处理全部待处理任务。指定 IQ 则只做该任务，找不到就停止，不回退全量；将示例编号换成实际编号。

仅输入技能名会说明用法；用法、版本、更新、统计和配置请求不会启动询价。

需要补充 ERP 网址或选择方案时，按输入/选择提示回答，AI 会继续原请求；单独修改配置或网址只完成该修改。开启 `confirmBeforeSend` 时，AI 发询价前会汇总店铺和话术，取得你的同意后才发送。

需要停止时说「停止询价」或「停」，等 AI 确认并汇报。以后重新启动同一 IQ，会先核原记录，从未完成部分继续，不重复已确认的消息或提交。

普通滑块起止点明确时，AI 可尝试一次并核验；失败或其他验证会请求协助。需要人工时，在 BrowserOS 处理后按 **Hand back**，AI 自动检查并继续，无需回聊天说「继续」。接管请求默认总时限20分钟；协助取消、超时或反复核验仍未解决时，停止对应平台，其他平台继续至当前 IQ 结束；ERP 登录协助失败只暂停回填，本机结果保留。细则见[验证与接管规则](references/execution.md#暂停与恢复)。

## 5 查看版本

对当前 AI 说：「查看烛龙智能询价的实际版本和目录，不运行询价。」反馈问题时附上名称、版本和目录，便于确认是否用了旧副本。

## 6 数据目录

个人配置和业务数据保存在系统用户主目录下的 `.zhul-trade-sourcing`，与仓库和安装位置分开：

| 系统 | 完整数据目录 |
|---|---|
| Windows | `C:\Users\<用户名>\.zhul-trade-sourcing\` |
| macOS | `/Users/<用户名>/.zhul-trade-sourcing/` |
| Linux | `/home/<用户名>/.zhul-trade-sourcing/` |

自定义主目录时，以当前电脑实际路径为准。对 AI 说「查看烛龙智能询价配置」即可查看真实数据和配置路径。

| 文件或子目录 | 用途 |
|---|---|
| `settings.json` | 个人配置 |
| `config.json` | ERP 网址 |
| `contacts.json` | 平台买家账号内的会话映射，账号或会话变化时重新核验 |
| `runs/` | 任务过程、断点及结果 |
| `records.jsonl`、`processed-tasks.jsonl` | 询价历史及任务处理记录 |
| `learnings/`、`reports/` | 本机页面经验与运行报告 |

更新时保留整个数据目录。报价、记录和报告属于内部数据，不放进公开仓库。

## 7 更新

1. 正在询价时先说「停止询价」，等 AI 确认停止并汇报。
2. 按[技能库更新说明](../../README.md#更新)在原仓库更新；本地有修改或冲突时联系维护者，不强制覆盖。
3. 查看 [CHANGELOG.md](CHANGELOG.md)，新开会话并按第5节确认实际版本和目录。

更新保留个人配置与业务数据；未指定的配置项继承新版默认值。

## 8 常见问题

| 情况 | 怎么处理 |
|---|---|
| AI 找不到技能，或版本不对 | 确认安装给当前客户端，新开会话；按[安装说明](../../README.md#安装)检查旧副本或失效链接 |
| 安装提示已有目录或链接冲突 | 按[安装说明](../../README.md#安装)处理，不直接覆盖 |
| `node` 找不到或版本过低 | 安装 Node.js 18 或以上，重新打开终端和 AI 会话 |
| BrowserOS 连不上或需要登录/验证 | 按 AI 提示协助；页面接管见第4节 |
| 更新提示本地修改、分支冲突 | 联系维护者处理，不强制覆盖或重置 |
| 提示 ERP 接口已修改 | 先按第7节更新；仍提示时联系维护者 |
