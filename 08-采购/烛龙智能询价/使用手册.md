# 烛龙智能询价 · 使用手册

适用版本：2.6.1。版本变化见 [CHANGELOG.md](CHANGELOG.md)。

## 1 能做什么

把 ERP「我的询价」里的任务交给 AI，自动在淘宝、1688 找店询价、跟进回复，并把整理好的报价提交回 ERP。

支持指定任务或逐个处理全部待处理任务，调用方式见[开始使用](#4-开始使用)。默认会真实发送询价消息并提交回价。每个平台完成后先保存本机结果并由主代理代存 ERP 草稿；全部平台真正完成或你明确跳过后才正式提交。某平台中断时，其他平台继续至结束，本轮停在当前 IQ，只留草稿。ERP 登录失败只暂停写回，本机询价结果仍会保留。

## 2 使用前准备

- **Git**：用于获取和更新技能库。
- **Claude Code 或 Codex**：任选其一，已安装并登录。
- **Node.js 18 或以上**：在终端执行 `node --version` 检查；没有或版本过低时先安装、更新。AI 客户端不一定附带 Node.js。
- **BrowserOS neo**：已安装，并把 MCP 连接到你使用的 AI。
- 在 BrowserOS neo 中登录公司 ERP 采购账号、淘宝买家账号和 1688 买家账号。遇 ERP 登录表单时，AI 会在提交前主动勾选并确认「记住我」或对应「自动登录」选项；密码、验证码仍由你处理，已有会话直接复用。

开始询价时，AI 会先检查连接；确认 BrowserOS 尚未运行时，使用本机真实应用入口启动一次，并在最多 120 秒内检查 MCP 是否连通后继续。首次配对、工具未接入、权限需你批准或等待超时等情况，会说明具体协助事项。无需预先手动安装站点脚本、找脚本目录、设置环境变量或反复重启。AI 内部准备方法见[浏览器准备](references/browseros-setup.md)。

### 配置

各项含义见[配置说明](references/settings.md)，发布默认值见 [settings.json](settings.json)。个人设置保存在[数据目录](#6-数据目录)的 `settings.json`：逐字段优先使用个人值，未设置的字段继承默认值。可以直接在聊天里查看或修改：

| 操作 | Claude Code | Codex |
|---|---|---|
| 查看当前配置表格（含说明） | `/烛龙智能询价 settings` | `$烛龙智能询价 settings` |
| 修改指定项 | `/烛龙智能询价 settings 把首次人工回复等待时间改为 8 分钟` | `$烛龙智能询价 settings 把首次人工回复等待时间改为 8 分钟` |
| 恢复指定项 | `/烛龙智能询价 settings reset firstHumanReplyMinutes` | `$烛龙智能询价 settings reset firstHumanReplyMinutes` |
| 恢复全部默认 | `/烛龙智能询价 settings reset --all` | `$烛龙智能询价 settings reset --all` |

查看只读，会列出有效值、来源和本机完整路径；明确要求修改时，只保存指定字段到个人配置，保留已有个人设置。这些操作都不启动询价。同一电脑、同一系统用户的 Claude Code 和 Codex 共用个人配置，每次开始新询价重新读取；更新技能不会覆盖它。修改前先结束或停止正在运行的询价，并等 AI 确认。恢复默认会移除指定或全部个人覆盖，继续继承当前及未来默认值；全部恢复仅清空个人设置，保留 ERP 地址和业务数据。也可手改个人配置；细则见[查看和修改](references/settings.md#查看和修改)。

## 3 安装

先按[技能库安装说明](../../README.md#安装)安装 Git、克隆仓库；已有仓库直接进入原目录。以下命令在仓库目录执行，只装询价技能，同时供 Claude Code 和 Codex 使用。

### Windows：在 PowerShell 中执行

```powershell
.\install.ps1 -Agent both -Skill "烛龙智能询价"
```

### macOS / Linux：在终端中执行

```bash
chmod +x install.sh
./install.sh --agent both --skill "烛龙智能询价"
```

只用一个客户端时，把 `both` 换成 `claude` 或 `codex`。安装全部技能、默认客户端、链接方式和 PowerShell 执行策略问题见上述技能库安装说明。安装后保留仓库原位置；询价技能的链接路径如下：

| 系统 | Claude Code | Codex |
|---|---|---|
| Windows | `C:\Users\<用户名>\.claude\skills\烛龙智能询价\` | `C:\Users\<用户名>\.agents\skills\烛龙智能询价\` |
| macOS | `/Users/<用户名>/.claude/skills/烛龙智能询价/` | `/Users/<用户名>/.agents/skills/烛龙智能询价/` |
| Linux | `/home/<用户名>/.claude/skills/烛龙智能询价/` | `/home/<用户名>/.agents/skills/烛龙智能询价/` |

表中使用常见用户主目录；自定义主目录时，以 Windows 的 `%USERPROFILE%` 或 macOS/Linux 的 `$HOME` 为准。仓库中的源码位置始终是 `<仓库目录>/08-采购/烛龙智能询价/`，安装后的链接指向它。

旧名 `烛龙AI询价`、`zhul-trade-sourcing` 的副本或链接，应先移到所有技能搜索目录以外备份，再重新运行安装命令；Codex 旧目录中的重复技能同样处理，目录定位见[技能库安装说明](../../README.md#安装)。仅在搜索目录内改成「备份」名称仍可能被识别。保留本机业务数据；安装脚本不会自动删除、迁移旧副本或覆盖冲突目录。

## 4 开始使用

安装后**新开 AI 会话**，按第 5 节确认实际版本和目录，再选择任务范围：

| 客户端 | 逐个执行全部待处理任务 | 只做指定任务 |
|---|---|---|
| Claude Code | `/烛龙智能询价 start` | `/烛龙智能询价 IQ20261016001A` |
| Codex（桌面 / CLI / IDE） | `$烛龙智能询价 start` | `$烛龙智能询价 IQ20261016001A` |

明确调用本技能执行询价时，`start` 可替换为「询价」「开始」「处理」，四者均逐个执行全部待处理任务；已提交、已跳过的任务不会自动重做；同 IQ 有未完断点时优先恢复原记录，已完成的平台不重新询价，未完成的平台先核对停机期间新回复及已发送消息。只做一个任务时，把示例编号换成实际任务编号；指定编号优先，找不到就停止并告知，不回退处理全部任务。AI 开始时会说明本次范围。

只输入技能名时，AI 说明上面两种调用方式；用法、如何开始、版本、更新和配置请求只做对应说明、查询或修改。即使这些请求中包含「开始」「询价」或示例编号，也不会启动询价。

需要停止时，在当前会话说「停止询价」或「停」，等 AI 确认已停止并汇报进度；停止后不会自动续跑，也不会继续写 ERP；进度保存为断点。后续重新启动同 IQ 会先核实原断点和 ERP 内容，再从未完成部分继续，不重发已确认发送的询价、追问或道谢。

首次运行需要补充 ERP 网址、配置含糊或需要业务选择时，AI 会优先使用当前客户端可用的原生输入/选择框；没有该工具或工具会阻碍业务截止检查时，在聊天里询问。答案校验通过后回到原请求继续；只修改配置或 ERP 地址的请求，保存后即结束，不启动询价。发询价前是否确认由 `confirmBeforeSend` 控制：开启时每个 IQ 汇总全部未跳过平台的店铺与话术确认一次。未回答、关闭输入框或拒绝方案都不会被当成同意；原报价截止仍有效，停止后或方案已到截止，迟到答案不会恢复发送。

ERP 地址直接填域名或 IP 即可，例如 `erp.example.com`、`localhost:8000`；IPv6 用 `[::1]:8000` 这样的括号写法。未填协议默认 `http://`，网站自动跳转 HTTPS 后正常继续；粘贴完整 HTTP(S) 地址时保留原协议。端口可选，不猜补端口，忽略页面路径。需要更换时说「修改 ERP 地址」。

遇到浏览器页面的登录、验证码或其他需人工操作的阻塞，AI 会通过 BrowserOS 发起接管请求；处理后按 **Hand back** 即可，AI 会检查页面并自动继续，无需回聊天输入「继续」。每次浏览器接管请求默认总时限 20 分钟，取消、超时或同一问题交回后连续两次检查仍未解除时，尚未进入任务则结束本轮准备；已有任务则中断受影响平台，其他平台继续至结束，本轮不取下一 IQ。ERP 人助失败只暂停写回，本机结果保留。任务结束后查看结果汇报；需人工处理时，先核实 ERP 当前状态。

浏览器会话失效后，AI 会先核实原任务标签的归属和登录状态。消息发送或 ERP 提交结果不确定时，先只读核对原结果；恢复连接或重新登录不代表可以重复发送、提交。

## 5 查看版本

对正在使用的 AI 说：「查看烛龙智能询价的实际版本和目录，不运行询价。」AI 会报告名称、版本和实际读取的目录；反馈问题时附上这三项，方便确认是否用了旧副本。

也可以在终端运行以下只读命令。示例使用 Codex 的安装目录；Claude Code 将 `.agents` 换成 `.claude`：

**Windows PowerShell**

```powershell
node "$env:USERPROFILE\.agents\skills\烛龙智能询价\scripts\records.mjs" version
```

**macOS / Linux**

```bash
node "$HOME/.agents/skills/烛龙智能询价/scripts/records.mjs" version
```

命令不开始询价、不初始化或修改业务数据、不安装站点脚本，也不检查远程更新。终端查到的版本只代表指定目录，仍需确认 AI 正在使用它。

## 6 数据目录

个人配置与业务数据都在**系统用户主目录**下的 `.zhul-trade-sourcing`，与仓库、技能安装位置分开，技能改名不改变它：

| 系统 | 完整数据目录 |
|---|---|
| Windows | `C:\Users\<用户名>\.zhul-trade-sourcing\` |
| macOS | `/Users/<用户名>/.zhul-trade-sourcing/` |
| Linux | `/home/<用户名>/.zhul-trade-sourcing/` |

以上是常见主目录；自定义主目录时以 Node.js 识别的系统用户主目录为准。对 AI 说「查看烛龙智能询价配置」，即可只读查看当前电脑的实际数据目录、默认配置和个人配置的绝对路径；目录尚未创建也能查看。

| 目录内文件或子目录 | 用途与创建时机 |
|---|---|
| `settings.json` | 个人配置，只存明确指定的字段；首次保存配置时创建，查看不会创建 |
| `config.json` | ERP 网址，与个人配置文件不同；首次保存 ERP 地址时创建 |
| `contacts.json` | 当前平台和买家账号内的会话映射；首次保存已核实身份时创建，查询不会创建。账号变化、身份冲突或会话失效时重新核验，不是跨账号通用或永久商家身份 |
| `runs/` | 每次任务的过程与平台记录；正式询价准备时创建目录，执行任务时写入 |
| `records.jsonl`、`processed-tasks.jsonl` | 询价历史、已提交/跳过/转人工的任务记录；有相应记录时写入 |
| `learnings/`、`reports/` | 本机页面经验与实跑报告；正式询价准备时创建目录，有内容时写入 |

首次保存个人配置时，仅创建数据目录和个人 `settings.json`，不初始化业务目录或 ERP 地址。更新时保留整个数据目录；其中的报价、记录和报告属于内部数据，不放进公开仓库。

## 7 更新

1. 如果询价正在运行，先说「停止询价」，等 AI 确认已停止并汇报进度，再关闭旧会话。
2. 按[技能库更新说明](../../README.md#更新)回原仓库拉取更新；通用的重新安装、仓库搬动和拉取冲突处理也见该处。技能改名时，先按本手册第 3 节移出旧名副本或链接，再按新名安装。
3. 查看 [CHANGELOG.md](CHANGELOG.md)，新开会话，按第 5 节确认实际版本和目录。安装链接指向仓库里的实际源码，新会话重读更新后的技能与说明，后续脚本调用读取最新文件；运行中的旧任务不保证热更新。

每次开始询价会重读最新默认配置与本机个人覆盖：个人覆盖字段保持原选择，其余字段随新版默认值更新。AI 会按 ERP 和本次启用平台的相关域核对站点脚本的完整内容，自动替换可识别的旧官方版本，并在下一次浏览器调用核验实际加载；停用域到启用时再处理。如提示存在来源不明的版本或本机改进，会保留并说明，需维护者合并或你明确选择后才替换，不能当作已同步。更新机制不会替你后台拉取远程仓库。

## 8 常见问题

| 情况 | 怎么处理 |
|---|---|
| AI 找不到技能，或版本不对 | 确认装给了当前 AI，并新开会话；按第 3 节检查旧副本、重复技能或失效链接 |
| 安装提示已有文件夹或链接冲突 | 将旧副本或链接移到所有技能搜索目录以外备份，再运行安装脚本 |
| `node` 找不到或版本过低 | 安装 Node.js 18 或以上，再重新打开终端和 AI 会话 |
| BrowserOS neo 连不上 | AI 先检查并尝试恢复；若提示首次配对、权限或超时等具体阻塞，按提示协助 |
| 需要登录、验证码 | ERP 登录时 AI 先核验记住我选项；你完成登录或验证后按 Hand back，AI 检查并继续 |
| `git pull` 提示本地修改、分支冲突 | 联系维护者处理，不强制覆盖或重置本地文件 |
| 提示 ERP 接口已修改，需要更新技能 | 先按第 7 节更新；仍提示时联系维护者 |
