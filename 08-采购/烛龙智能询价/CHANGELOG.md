# 烛龙智能询价 · 版本变化

2.1.0–2.3.0 按独立交付单元递进整理，并在同一个 PR 中发布；这些条目的日期是整理日期，不表示曾分三次对外发布。正文只描述当前版本。

## 2.7.0（2026-10-18）

- 起止点明确的普通滑块，在没有未决人工接管请求时由AI尝试一次并实际核验；失败、不确定或其他验证立即人助。使用当前快照/视口定位，变化后重定位，不读凭据、不刷新重试、不用解题/token服务，waiting不操作受阻页。
- 现有incidents先记稳定事件意图，意图即消耗一次；未知结果不再拖，刷新/重派/重连/换页不重置，恢复先查记录。脚本只保留事件，不新增防重状态机、solver、配置或schema；自动失败不计人工交回核验次数。
- ERP_LOGIN仅提示文字同步例外并保留旧官方hash迁移，登录守卫与业务逻辑不变。ERP203/helpers38复验及6次隔离CLI事件/原发送断点保留通过；两Junction沙箱受限后经正常授权定向通过。本轮未遇真实滑块、无合成滑块UI操作，不称实际自动过验通过。
