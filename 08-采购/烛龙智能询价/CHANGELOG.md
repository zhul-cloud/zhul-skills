# 烛龙智能询价 · 版本变化

本页记录各版本当时的变化与验证边界，历史行为不作为当前操作指南；执行以当前 SKILL 和引用文档为准。2.1.0–2.3.0 为同一 PR 中整理的连续交付单元，日期不代表分别发布。

## 2.8.0（2026-10-19）

- 测试阶段升级后的首次 `records.mjs init` 清空并重建整个个人数据目录，不自动迁移或备份；需留存资料在初始化前人工收集。重建含配置、ERP 地址、身份映射、断点、历史、经验及报告，不清 BrowserOS 登录/helper 或 ERP 服务器数据；正式发布策略另行调整。
- 增加最后落盘的语义版本标记、外部生命周期短锁及 CLI 写入口版本守卫。同版保留数据；旧副本拒绝回退清理，损坏/未知标记报错保留。当前发布内容与显式 ERP 参数先校验，重建不解析旧配置；链接和重解析预检限定删除范围，锁不能停止不支持协议的旧执行者或直接文件写入。
- 正式询价准备改为先初始化、再读取有效配置；明确配置修改/reset 在意图清楚且执行者已停后遵循相同顺序。只读查看不初始化，初始化/重建时告知结果；正式询价补齐缺失 ERP 地址，独立个人设置修改不要求补 ERP，个人设置使用新版默认值或用户明确指定值。升级后的旧断点和防重复历史不再可用。
- Windows 隔离 CLI 回归通过，覆盖新增数据生命周期及相关既有功能，验证入口与边界见[采购验证表](../README.md#按改动选择验证)。本次未初始化或清理真实个人目录，未新增 macOS/Linux、真实浏览器、商家发送或真实 ERP 写入验收。
