# 测试阶段个人数据生命周期

当前测试阶段，每次升级技能后首次初始化都会清空并重建整个 `<数据目录>`，不自动迁移或备份；正式发布时再另行调整策略。用户操作见[手册「更新」](../使用手册.md#7-更新)。本协议只管理本机个人数据，不检查远程 Git、源码 hash，也不热更新正在运行的任务。

## 初始化与版本判断

只有 `node "<技能目录>/scripts/records.mjs" init`（含显式 `--erp <地址>`）执行版本生命周期处理。版本取当前 `SKILL.md`，按三段语义版本比较；成功完成初始化后，最后写入 `<数据目录>/.skill-version.json`：

```json
{ "schemaVersion": 1, "skillVersion": "2.8.0" }
```

| 数据状态 | `init` 行为 |
|---|---|
| 目录不存在或为空 | 创建当前版本所需目录和文件，写入版本标记 |
| 非空目录没有标记 | 视为旧数据，完整清空后重建 |
| 标记版本低于当前技能 | 完整清空后重建，仅执行一次 |
| 标记版本等于当前技能 | 保留现有数据，补齐必要目录，读取并校验已存 ERP 地址；个人设置留给后续 `settings.mjs json` 检查 |
| 标记版本高于当前技能 | 拒绝回退初始化，不清理；使用相应新版 |
| 标记损坏、未知结构或版本无效 | 报错并保留数据，交维护者核对，不删标记绕过 |

重建覆盖个人 `settings.json`、ERP `config.json`、`contacts.json`、`runs/` 断点、询价/处理历史、`learnings/`、`reports/` 及目录内其他内容；不删除 BrowserOS 的登录和已注册 helper，也不修改 ERP 服务器数据。跨版本后原断点、历史防重复和身份映射均消失，不能承诺继续旧进度或不再询问旧店。同一版本内按原恢复协议处理。

脚本先校验当前 SKILL 版本、发布默认值及显式 ERP 参数，再开始生命周期处理；这些发布内容或新输入非法时不清旧数据。授权重建不解析旧个人设置及 ERP 配置，旧文件损坏不阻止版本重建。同版的个人配置错误仍按[配置校验与修复](settings.md#校验边界)处理，不用清目录修复。

## AI 调用顺序

- **正式询价**：先确认旧执行者已停，执行 `records.mjs init`，再执行 `settings.mjs json` 校验并读取有效配置；通过后输出运行提醒，再补齐 ERP 地址、准备 BrowserOS。
- **明确修改个人配置或 reset**：先确认具体项/值或范围清楚，且询价执行者已停，再 `init` → 读取当前配置 → 执行指定修改。`reset` 本身仍只移除指定个人覆盖；同版 `reset --all` 不动 ERP 或业务记录。跨版本先发生的完整重建属于 `init`，不得混称为 reset 的作用。
- **明确修改 ERP 地址**：沿用 `records.mjs init --erp <地址>`；先确认执行者已停及地址意图清楚。
- **仅查看**：`version`、settings 表格/`check`/`json`、`stats`、contacts `lookup` 只读现存数据，不运行 `init`，不宣称当前版本已初始化。读取文件、导入模块本身不触发删除。

每次 `init` 返回 `dataRebuilt:true`，告知用户「已为当前版本初始化/重建空白个人数据目录」，说明当前使用新版默认设置；用户已有明确个人设置要求时按配置流程保存，不新增可选配置问答阻塞询价。只有正式询价准备缺 ERP 地址，或用户明确修改 ERP 却缺值时，才按[既有提问分支](execution.md#何时提问答后回到哪里)补齐；本次显式传入的地址不重复收集。独立 settings 修改/reset 允许 `erpUrl:null`，完成指定配置即结束，不要求补 ERP。测试阶段的重建已获授权，不另加一次清空确认。初始化报错就停止依赖动作，不手工删标记、锁或旧文件绕过。

## 并发与删除范围

生命周期短锁位于同一系统主目录的 `.zhul-trade-sourcing.lifecycle.lock`，在数据目录之外。其他 CLI 写入口持锁并检查版本：尚未初始化或版本不一致时拒绝，提示先停止执行者再 `init`，不能顺带重建。已有锁保留并报忙，不自动删锁。

锁仅协调支持该协议的新版 CLI，不能停止旧代码或 AI 直接写文件。更新前必须停止所有旧执行者并确认已停；需留存的旧资料必须在新版首次 `init` 前人工收集，清理后无法追回。目录及父链的链接/重解析预检用于限定生命周期删除范围，不是所有业务文件写入的通用路径沙箱。
