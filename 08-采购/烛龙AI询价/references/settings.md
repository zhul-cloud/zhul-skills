# settings.json 配置说明

`settings.json` 放在技能根目录，保存询价时所有可调的数字和开关。技能文档里只写键名，具体取值一律以这个文件为准。

## 怎么改

1. 用任意文本编辑器（Windows 记事本、macOS 文本编辑）打开技能文件夹里的 `烛龙AI询价/settings.json`。
2. 只改冒号后面的值，**不要改键名**，不要删逗号、引号和大括号。
3. 保存后，**新开一个 AI 会话**才会生效；正在运行的询价任务不受影响。
4. 改完可以让 AI 检查：「帮我检查一下询价设置」。AI 会读出每一项的当前值；格式写错时会指出哪一行。

> JSON 文件里不能写注释，说明都放在本文。所有采购共用同一份默认值，个人想改，改自己电脑上的这份即可；升级技能时整个文件夹会被替换，改过的值需要重新改一次（见文末）。

## 当前默认值

```json
{
  "confirmBeforeSend": false,
  "shopsPerChannel": { "min": 3, "max": 3 },
  "replyTimeoutMinutes": 30,
  "pollIntervalSeconds": { "min": 10, "max": 30 },
  "maxFollowUpsPerShop": 1,
  "dedupeDays": 7,
  "priceOutlierPercent": 30
}
```

## 各项说明

### confirmBeforeSend：发询价前是否先让采购确认

| 取值 | 效果 |
|---|---|
| `false`（默认） | **自主执行**。AI 挑好店直接发询价，全程不停下来问，最后统一汇报 |
| `true` | AI 挑好店后，先把店铺清单和要发的话术列给采购，得到同意后再发。一个任务只确认一次 |

- 只管「发询价」这一步。登录失效、验证码、账号异常这类情况，不论取值如何，AI 都会停下来请采购处理。
- 什么时候改成 `true`：新人刚开始用、换了新的平台、或者对这个任务的店铺选择没把握时。

### shopsPerChannel：每个平台询价几家店

- `min`：至少问几家；`max`：最多问几家。两个数相同就是固定家数。默认固定 3 家。
- 按平台分别计算：一个任务同时在淘宝、1688、闲鱼询价时，每个平台各问这么多家（启用了几个平台见 SKILL.md「启用的平台」）。
- 型号匹配的店多于 `max` 时，从排名靠前、有成交的店里挑；少于 `min` 时，有几家问几家，不拿错型号或重复店铺凑数。
- 问完不补店：挑出的店有没回复的，不再另找新店补问。
- 例：想问 3 到 5 家，改成 `{ "min": 3, "max": 5 }`。
- 建议范围：1 到 5。家数越多，等回复和整理的时间越长，淘宝账号短时间内发消息过多也更容易触发验证。

### replyTimeoutMinutes：等店家回复的最长时间（分钟）

- 每个平台分别计时，从该平台**最后一家询价发出**的时刻算起。到时间仍没回复的店记为「未回复」，然后提交回价。
- 在这段时间内，所有店都会持续查看，包括已经报过价、追问次数已用完的店，店家可能会补充信息。
- 所有店都回复齐、该追问的也追问完，会提前结束，不必等满。
- 建议范围：15 到 60。淘宝工控店大多 1 分钟内回复，个别要几分钟到半小时。

### pollIntervalSeconds：查看回复的间隔（秒）

- `min`：最短间隔；`max`：最长间隔。
- 从最短间隔开始查；连续没有新回复，逐步拉长到最长；一有新回复，缩回最短。
- 建议 `min` 不低于 10。查得太频繁会增加淘宝风控的风险，也更费 AI 用量。

### maxFollowUpsPerShop：每家店最多追问几次

- 询价话术本身不算追问。默认 1 次：店家漏答的价格、含税、货况、货期，合成一句问一次。
- 发错对象后的更正消息不算追问（见 SKILL.md「发错对象时」）。
- 建议 0 到 2。设为 0 表示只发询价话术、不追问，漏答的项留空。

### dedupeDays：多少天内不重复询价同一家店

- 本机记录里，同一型号在这么多天内问过的店家，这次不再发消息：
  - 当时报过价的，直接沿用那次报价，备注写明「沿用 x 月 x 日回复」；
  - 当时没回复的，这次跳过。
- 设为 0 表示不防重复，每次都重新问。
- 记录只在本机，换电脑或别的采购问过，不会被识别。

### priceOutlierPercent：价格异常的判断标准（百分比）

- 某家的不含税单价比其他店的中位价低这么多以上，标为「价格异常」（可能是假货、翻新或标错价），写进该条报价的备注，并在汇报里提醒。
- 默认 30：中位价 2000 时，低于 1400 就标出。
- 只提醒，不会删掉这条报价。

## 升级技能时保留自己的设置

升级是用新版文件夹整个替换旧的，`settings.json` 会变回新版的默认值。替换前先把自己改过的值记下来，替换后再改回去。新版如果增加了新键，以新版文件为准，不要删掉新键。
