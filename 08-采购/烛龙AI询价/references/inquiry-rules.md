# 询价规则

整理自公司《采购岗位 SOP》和《询盘单 Excel 操作手册（含店铺筛选标准）》，只保留 AI 在电商平台询价时用得上的部分。文中的英文键名（如 `shopsPerChannel`）指技能根目录 `settings.json` 里的设置，含义见 [settings.md](settings.md)。两份文件有冲突时，以本文为准；本文没写到的，以 SOP 为准。

## 1 四个原则（SOP 第一章）

- **快**：不拖延，但不为了快而漏问关键信息。
- **准**：型号、数量、货期一个都不能错。差一个字母，可能差十倍价格。
- **稳**：记下的必须是「实际能拿到货」的价格，不能为了好看往低了写。
- **留痕**：每家的店铺、链接、店家原话都要存档（写进 `run.json`，报价备注里也写原话摘要和链接）。

## 2 搜索（SOP 第三章、手册第 1 节）

- 先用精确型号搜。搜索结果不足时，再依次用核心系列、去连字符、中文品牌的关键词搜。任务页面的货源直达链接已经按这个顺序排好。
- 型号的大小写、连字符、斜杠都是型号的一部分，复制时不得缺少字母或后缀。
- 标题写「现货」不等于真有货，必须和卖家文字确认。

## 3 店铺筛选标准（手册第 2 节）

1. **关键词匹配**：只选与搜索关键词（型号）匹配的店铺。标题里的型号对不上的不选。
2. **排除**：广告位；标题写「基本全新」「二手」「拆机」「翻新」「99新」的；明显不可能的占位价（如工控件标 ¥20、标题以「议价」开头且 0 人付款）。
3. **排序**：在剩下的店铺里，排名靠前、有付款（成交）记录的优先；商品页显示客服回复慢、发货慢的往后排。
4. **确定询价店铺数**：每个渠道询价的家数按 `shopsPerChannel`。匹配的店铺多于最多家数时，按上面的优先顺序取；不多于最多家数时，全部询价。
5. **不追加店铺**：挑出的店家问完就结束，不因为有店家没回复而再找新的店家补问。
6. **没有回价时**：该渠道至少要有 1 个价格。问过的店家都没有报价时，可以记录这些店铺商品页的公开挂牌价，货况写「待确认」，备注写明「公开挂牌」。一个价格都没有的，该渠道按无货处理。
7. **例外**：因页面需登录、验证码或账号失效而无法询价的，不算无货，停下来请采购处理。
8. 不得用重复店铺或错型号凑数。

## 4 询价话术（SOP 第四章、手册第 3 节）

**单个型号**：用系统提供的询价话术，**末尾补一句「另外请说一下是否全新原装。」**（临时规则，见 SKILL.md「运行前提醒」），例如：

> 帮我查一下松下（Panasonic）的 MFDLTA3SF，要 1 台，报不含税价，有货的话货期也说一下，谢谢。另外请说一下是否全新原装。

系统话术没有问新旧，不补这一句时，大多数店家需要为此追问；而一次追问问多项时，店家常只答其中一项。

**多个型号**（同一家店问本任务的几个型号）：用 SOP 的在线询价模板：

> 您好，请帮忙查询以下松下产品的价格和货期：
> 1. MFDLTA3SF × 1台
> 2. MADLN15SE × 2台
> 请注明：不含税价、货期、是否现货、是否全新原装。谢谢！

**追问**（次数不超过 `maxFollowUpsPerShop`，只问缺的）：

| 缺什么 | 追问 |
|---|---|
| 价格 | 麻烦报一下不含税单价，谢谢。 |
| 是否含税 | 这个价格含税吗？ |
| 货期 / 是否现货 | 请问是现货吗？多久能发货？ |
| 新旧 | 请问是全新原装的吗？ |

缺多项时合成一句问，仍然只算一次追问。

**道谢**（只在信息齐全时发）：单价、是否含税、货况、货期都答齐后（只说「含税」没说票种的也算齐全），从 `thankYouMessages` 里挑一句发出，表示这家的询价结束。同一个任务里尽量不重复。道谢不算追问。

## 5 等待回复（SOP 第六章 Q2）

- 同时联系多家，谁先回先处理，不按顺序等。
- **每家店分别计时**：发出询价后 `firstHumanReplyMinutes` 内没有人工回复的，这家结束（没回复记「未回复」，只有机器人回复记「自动回复」）；追问后 `followUpReplyMinutes` 内没回答的，这家按已有信息结束。是否超时按店家消息上显示的发送时间判断，不按读到消息的时间。
- **机器人回复不算人工回复**，继续等人工，也不重新计时。判断方法：
  - 消息带「智能客服」「智能客户专员」等机器人标记（各平台的标记见平台说明）；
  - 欢迎语和固定话术：「亲，在的」「欢迎光临」「您好，稍等」「您咨询的这款不是当前商品」，以及进入聊天时自动发出的店铺介绍；
  - 平台系统提示：如「商家长时间没有回复，平台已通知商家」。
- **店家结束聊天**：出现平台的结束信号（淘宝是店家客服发的「您对客服的服务满意吗」，1688 是「客服评价邀请」），说明聊天已关闭，这家立即结束，不再发送任何消息。结束信号由店家客服主动发出，不一定会出现；没出现不代表聊天还在进行，这家照常按计时和信息是否齐全结束。
- 所有店都结束后立刻整理报价，不再等待；报价截止前 5 分钟仍没结束的，一律按已有信息结束。截止时刻按读任务时的剩余分钟算出（见 SKILL.md 第 1 步）。

## 6 把回复整理成报价

**错别字和简写**

店家客服常用拼音输入法快速回复，会打出同音或首字母相同的错字，如「型号」（xh）其实是「现货」。按下面的方法处理：

1. **结合刚问的问题理解**：回复和问题对不上、但换成同音或拼音首字母相同的词就对得上时，按对得上的意思理解。例：问「是现货吗？多久能发货？」，回「型号 含税」，按「现货，含税」理解。
2. **备注保留原话**：在该条报价的备注里写原话和理解，如「店家原话『型号 含税』，按『现货、含税』理解」。
3. **拿不准时**：同一处有几种理解都说得通，或换词后仍对不上：
   - 追问次数没用完的，在追问里一并确认这一项；
   - 追问次数已用完的，按最保守的方式记录（货况「待确认」、货期留空），并在备注里写明原话和「含义不确定」。
4. 价格数字有歧义（如少一位、多一位）时，不自行推断，按第 3 条处理。

**单价**

- 记人民币不含税单价。店家只给含税价时，按含税记录，税率按发票类型定：

  | 店家说法 | 记录为 |
  |---|---|
  | 不含税 | 不含税 |
  | 含普票、普通发票 | 含税，税率 3% |
  | 含专票、增值税专用发票 | 含税，税率 13% |
  | 只说「含税」，没说票种 | 含税，税率 13%，备注写明「票种未说明」 |

  这是临时规则，见 SKILL.md「运行前提醒」。
- 有数量阶梯价时，取本任务数量对应的那一档。
- 运费另计、有起订量时，写进该条报价的备注。

**货况**（必须用 ERP 下拉里的取值）

| 店家说法 | 货况 |
|---|---|
| 全新、原装、正品、全新原装 | 全新原装 |
| 99 新、九成九新、几乎全新 | 99新 |
| 翻新 | 翻新 |
| 二手、旧件 | 二手 |
| 拆机 | 拆机件 |
| 国产、兼容、替代 | 国产替代 |
| 没说清、只看到挂牌价 | 待确认 |

**货期**（必须用 ERP 下拉里的取值）

| 店家说法 | 货期 |
|---|---|
| 现货、当天发、今天能发 | 现货 |
| 1 至 2 天、明后天 | 1-2天 |
| 2 至 3 天 | 2-3天 |
| 3 至 5 天 | 3-5天 |
| 一周内、5 至 7 天 | 5-7天 |
| 1 至 2 周 | 1-2周 |
| 半个月到一个月 | 2-4周 |
| 1 至 2 个月 | 4-8周 |
| 2 个月以上、需订货且很久 | 8周以上 |

店家说的时间落在两档之间时，取较长的一档。没说货期的留空。

**无货**：店家明确说没货、缺货、断货，这家记为无货，原话记进 `reply`。一个型号在所有问过的店都没有价格时，才在 ERP 里给该型号勾「无货」。

**替代型号**：店家推荐替代型号时，不要当作原型号的报价。写进该店报价的备注「推荐替代型号 xxx，待技术确认」。

## 7 需要提醒采购的情况（SOP 第三、四章）

- **价格异常**：同型号某家的不含税单价比各家中位价低 `priceOutlierPercent` 以上，可能是假货、翻新或标错价，在该条备注和汇报里标出「价格异常」。只提醒，不删除这条报价。
- **价格仅供参考**：店家说「价格仅供参考」「以实际为准」，在备注里写明。
- **报价有效期**：店家主动说了有效期的，写进备注。
- **停产**：店家说已停产的，写进备注并在汇报里提醒。
