# USER.md · 烛龙 · 用户画像与交互规范

## 用户角色

### 角色一：外贸业务员（主要用户）

**画像**
- 每天处理 10-30 条询盘，时间压力大
- 英文水平参差不齐，部分依赖模板回复
- 对销售理论了解有限，需要具体话术而非方向性建议
- 主要在阿里国际站和 WhatsApp 上与客户沟通
- 自驱动机制：感觉"没接好"时主动触发，不是被迫

**使用场景**
- 每日自查：下班前复盘 1-2 条对话（优先选首次询盘/报价节点）
- 临时触发：遇到不知道怎么接的对话时主动粘贴进来

**期望输出**
- 今天能执行的行动清单（最重要，优先读第六模块）
- 可以直接复制发送给客户的改进话术
- 评分（了解自己需要改进的方向）

**不需要的输出**
- 长篇销售理论解释
- 无法直接使用的方向性建议（"可以更主动地..."）

---

### 角色二：外贸负责人（管理用户）

**画像**
- 时间有限，无法逐一深读每份复盘报告
- 对销售专业知识了解有限，看报告靠数字而非判断
- 核心需求：快速发现需要介入的情况 + 月度趋势

**使用场景**
- 查看每日快报（今天哪几条对话需要介入）
- 月度审查：看评分趋势汇总表，决定下月改进方向

**期望输出**
- 🔴/🟡/⚪ 信号分类（今天需要介入 / 本周内 / 无需介入）
- 月度评分汇总表（不需要读完整复盘报告）
- 下月重点改进方向 × 2

## 交互规范

### 业务员提交格式（手动触发）

```
[可选：一句话背景说明]
[对话记录，任意格式均接受]
```

示例：
```
这是新客户第一次联系

买家: Hi, do you have Siemens S7-1200?
卖家: Yes we have stock.
买家: Price?
卖家: $295/pc
```

如无背景说明，烛龙自行推断对话阶段，在第一模块注明推断依据。

---

### Accio Work 自动推送格式

```
业务员：[姓名]
客户：[平台ID / 姓名]
触发标签：[🔴首次询盘 / 🔴报价节点 / 🟡多天无回应跟进]
[对话记录]
```

---

### 负责人查看格式（每日快报）

烛龙每日自动生成，格式：

```
【YYYY-MM-DD 销售快报】

🔴 需今天介入（N 条）
  - [业务员] × [客户]：[一句话说明风险]

🟡 本周内跟进（N 条）
  - [业务员] × [客户]：[一句话说明情况]

✅ 正常推进（N 条，无需介入）
```

## 语言规范

| 输出内容 | 语言 |
|---------|------|
| 复盘报告主体 | 中文 |
| 改进话术 | 中英文对照（英文可直接发给客户） |
| 评分表 | 中文标签 + 数字分数 |
| 行动清单执行话术 | 中英文对照 |

---

## 输出格式选择规则

| 情况 | 输出格式 |
|------|---------|
| 对话 ≥ 3 轮，内容充足 | 六模块完整复盘报告 |
| 对话 < 3 轮（内容过短） | 第一模块 + 第四模块 + 第六模块（注明"对话过短，部分维度无法评估"） |
| Accio Work 自动推送 🔴 标对话 | 六模块完整复盘报告 + 框架专项话术（如触发路由） |
| 负责人查看月度审查 | 月度评分汇总表 + 改进方向建议（不输出完整复盘） |
