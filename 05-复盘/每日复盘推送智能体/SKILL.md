# 每日复盘推送智能体

> 烛龙自动化路线·阶段二：每天定时拉取阿里国际站店铺过去 24h 对话 → 按 SOP 信号规则打标 🔴🟡⚪ → 每人取最多 2 条 → 飞书 Bot Webhook 按业务员分别推送复盘卡片。

## 触发方式

以下任一情况触发本智能体：
- 定时任务每天 17:30 自动执行
- 用户手动说"执行每日复盘推送"/"跑一次打标任务"/"手动测试推送"

## 执行流程

### Step 1 · 拉取对话

通过国际站生意助手插件获取店铺过去 24 小时所有对话，按业务员子账号分组（映射关系见工作区 memory.md）：

- 2500001419423 → 郭如
- 2500001388527 → 朱娜芬
- 2217537475378 → 邱丽芳
- 2500000755363 → 杨礼凯

### Step 2 · 过滤 + 打标分类

每条对话先过 **F 层过滤**，通过后再打标。

**F 层（命中则丢弃，不进入打标）**：
- F1：卖家回复包含完整短语 `sorry, this model unavailable ,cann't supply this`（大小写不敏感，忽略多余空格和末尾标点）→ 无货对话，直接丢弃

> F 层规则可扩展，后续追加见 `SOP信号规则.md` §零。

**打标规则（F 层未命中的对话）**，输出：

```
[标色] 客户 [买家名] · [触发信号]
   → [一句中文理由]
   → 建议复盘重点：DimX [维度名]
```

- 🔴 = 今天新客户第一条消息 / 今天发出报价的对话
- 🟡 = 买家回复没接好 / 多天无回应（≥2天）待跟进
- ⚪ = 常规物流确认 / 已付款例行跟进 / 对话<3轮仅地址单号 / 低意向

### Step 3 · 每人取条

1. 每人每天**最多 2 条，宁可精选 1 条**，不凑数
2. 🔴 优先（每天至少 1 条）；多条 🔴 按最新时间排序取前 2
3. 无 🔴 时取 🟡（按最新时间排序）
4. 全部 ⚪ → 推送「今日无重点复盘项」
5. 只有 1 条 🔴 就只推 1 条

### Step 3.5 · 格式化对话原文

筛选出的每条对话，推送前先转换为烛龙可直接接受的格式：
- `from=buyer` → `买家: [text]`
- `from=seller` → `卖家: [text]`
- `[Card]` / `-` 内容跳过
- 超过 15 条 → 只取最近 15 条，加注说明

### Step 4 · 推送飞书

调用飞书 Bot Webhook（URL 见 memory.md），为每位业务员单独发一条消息，@ 对应人，**并在每条复盘项下附上格式化对话原文**，业务员长按即可复制粘贴到烛龙。

**消息格式**：

```
<at user_id="[ou_xxx]">[姓名]</at>

📋 今日复盘建议 · [姓名] · [YYYY-MM-DD]

🔴 客户 [买家名] · [触发信号]
   → [一句中文理由]
   → 建议复盘重点：DimX [维度名]

━━━ 复制以下内容粘贴到烛龙 ━━━
买家: ...
卖家: ...
━━━━━━━━━━━━━━━━━━━━━━━━━━

👉 打开烛龙话术复盘，粘贴对话即可
```

全部 ⚪ 时：
```
<at user_id="[ou_xxx]">[姓名]</at>

📋 今日复盘建议 · [姓名] · [YYYY-MM-DD]

今日无重点复盘项 ✅
```

## 约束

- 只推送有依据的信息，**不编造**买家名、金额、时间
- 打标存疑时降档处理（存疑 → 🟡），宁宽勿漏
- 4 位业务员各自独立推送，互不混发
