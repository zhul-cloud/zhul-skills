# USER.md · 每日复盘推送智能体 · 用户说明

## 本智能体的用户关系

本智能体是**自动化调度型**，主要由定时任务触发，不依赖用户主动输入。

有两类用户会与本智能体交互：

---

### 用户一：运营负责人（配置 & 维护）

**交互场景**
- 初次配置：上传工作区文件，设置定时任务
- 日常维护：调整可调参数（阈值、执行时间）
- 异常处理：查看执行历史，排查推送失败

**运营负责人能说的指令**

| 指令 | 说明 |
|------|------|
| 手动执行一次 | 立即跑一次完整流水线（测试用） |
| 推送到测试群 | 把 Webhook URL 临时换成测试群地址 |
| 调整 Y2 阈值为 3 天 | 修改 memory.md 中的 Y2 参数 |
| 查看昨天执行结果 | 在 Accio Work 对话线程中查看上次输出 |

---

### 用户二：业务员（推送接收方）

**交互场景**
- 每天 17:30 左右，在飞书群收到 @ 消息
- 点开消息，看今天建议复盘哪条对话

**业务员收到推送后的动作**（对齐烛龙SOP第一层）

```
Step 1   复制推送中的对话 → 粘贴到烛龙话术复盘
Step 2   优先读【第六模块：下一步行动清单】
Step 3   今天能发出去的话术 → 当天发出
Step 4   报告截图保存到对应客户文件夹
         命名格式：日期_客户名_关键词
         示例：20260807_John_首次询盘报价歧义
```

**判定标准**（SOP 原文）：看完报告后没有任何一条消息发出去，这次复盘等于没做。

| 输出内容 | 语言 |
|---------|------|
