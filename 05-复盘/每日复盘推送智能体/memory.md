## 推送消息中 @ 的写法

飞书自定义机器人文本消息中 @ 用户：

```json
{
  "msg_type": "text",
  "content": {
    "text": "<at user_id=\"ou_9304bc99a74992667f170afbe3186c65\">郭如</at>\n\n📋 今日复盘建议 · 郭如 · 2026-08-07\n\n..."
  }
}
```

或使用卡片消息（interactive），在 `content` 字段里加 `<at user_id=\"...\">姓名</at>`。
