# 每日复盘 · SOP 信号规则 v2（对齐烛龙复盘SOP v1.0）

> **用途**：复盘智能体按《烛龙话术复盘 · 三层业务改进 SOP v1.0》**第一层"选哪条对话复盘"**标准，对每条会话打标 🔴 / 🟡 / ⚪，输出「标色 + 触发信号 + 一句中文理由 + 建议复盘维度」。
> **版本说明**：v3（2026-08-07）——新增零号过滤层（F 层），在打标前先过滤无效/无需复盘的对话。
> **配套**：本文件放入智能体工作区，定时任务指令中引用「按 SOP信号规则.md 打标」。

---

## 零、过滤层（F 层）——打标前执行，命中则丢弃

> **执行时机**：在 🔴🟡⚪ 打标之前。命中任一规则 → 该对话直接丢弃，不进入打标流程，不计入推送。
> **扩展方式**：后续追加新规则只需在下表加一行（FX 编号递增）。

| 规则 | 过滤条件 | 说明 |
|------|---------|------|
| F1 | 卖家回复中包含完整短语 `sorry, this model unavailable ,cann't supply this`（大小写不敏感，忽略多余空格和末尾标点） | 无货/断货对话，商机已关闭，无复盘价值 |
| *(F2 预留)* | *(待追加)* | *(示例：买家账号在黑名单中)* |
| *(F3 预留)* | *(待追加)* | *(示例：对话语言为印地语/乌尔都语且无英文)* |

**与 ⚪ 的区别**：
- ⚪ = 有效对话但不值得复盘（如物流确认）→ 计入统计，显示为"已跳过"
- F 层 = 无效/已关闭对话 → 完全丢弃，不计入统计，不显示

## 一、复盘维度清单（6 维，来自烛龙月度评分汇总表）

| Dim | 维度 | 关注点 |
|---|---|---|
| Dim1 | 需求挖掘 | 是否先挖需求（项目/库存/规格/预算）再报价 |
| Dim2 | 情绪把控 | 异议/负面场景是否先共情、再给方案 |
| Dim3 | 推进节奏 | 跟进频率是否合适（过急/过缓），该推进时是否推进 |
| Dim4 | 专业度 | 参数、交期、认证等回答是否专业准确 |
| Dim5 | 英文质量 | 表达是否地道、无歧义 |
| Dim6 | 追加销售 | 是否主动挖掘追加/配套需求 |

## 二、打标规则（对齐 SOP 第一层"选哪条对话复盘"）

### 🔴 首选（每天至少复盘 1 条）

| 规则 | 信号描述 | 建议维度 |
|---|---|---|
| R1 | 今天收到的新客户第一条消息（首次询盘） | Dim1 需求挖掘 |
| R2 | 今天发出报价的对话 | Dim1 / Dim3 |

### 🟡 次选（有余力时）

| 规则 | 信号描述 | 建议维度 |
|---|---|---|
| Y1 | 买家回复了但回复质量存疑（"没接好"）：客户提问未直接回答 / 未挖需求直接报价 / 异议未处理 / 语气生硬等 | 按问题类型（未挖需求→Dim1；异议未处理→Dim2；表达生硬→Dim5） |
| Y2 | 多天无回应（≥2天）、今天准备跟进的 | Dim3 推进节奏 |

### ⚪ 跳过（不需要复盘）

| 规则 | 信号描述 |
|---|---|
| W1 | 常规物流确认 / 已付款客户的例行跟进 |
| W2 | 对话少于 3 轮且内容只是地址 / 单号确认 |
| W3 | 低意向或垃圾消息 |

> **自动化代理判断说明**：Y1"没接好"原是人工主观感受，自动化阶段用代理规则近似（见上表）；判断拿不准时**降档处理（存疑 → 🟡）**，宁宽勿漏。

## 三、打标输出格式（每条会话）

```
[标色] 客户 [买家名] · [触发信号]
   → [一句中文理由]
   → 建议复盘重点：DimX [维度名]
```

示例（与推送模板一致）：

```
🔴 客户 John Smith · 首次询盘
   → 客户问了详细规格但你直接报价，未挖掘需求
   → 建议复盘重点：Dim1 需求挖掘

🟡 客户 Maria García · 多天无回应
   → 跟进节奏可能过急
   → 建议复盘重点：Dim3 推进节奏
```

---

## 四、选条逻辑（宁少勿滥，对齐 SOP 核心原则）

1. 每人每天**最多 2 条，宁可精选 1 条**——不凑数
2. **🔴 优先**（每天至少 1 条）；多条 🔴 按最新时间排序，取前 2
3. 无 🔴 时取 🟡（按最新时间排序）
4. 全部 ⚪ → 推送「今日无重点复盘项」
5. 只有 1 条 🔴 就只推 1 条

---

## 五、与三层 SOP 的衔接（业务员收到推送后）

本规则实现**第一层「选哪条对话复盘」的自动化**（对应烛龙自动化路线·阶段二）。业务员收到推送后，按 SOP 第一层执行步骤操作：

```
Step 1   复制推送中的对话 → 粘贴到烛龙话术复盘
Step 2   优先读【第六模块：下一步行动清单】
Step 3   今天能发出去的话术 → 当天发出（"今天的对话今天改"）
Step 4   报告截图保存到对应客户文件夹
         命名格式：日期_客户名_关键词（示例：20260807_John_首次询盘报价歧义）
```

> **判定标准**（SOP 原文）：如果看完报告后没有任何一条消息发出去，这次复盘等于没做。

## 六、可调项

| 项 | 当前值 | 调整方向 |
|---|---|---|
| 每人每天上限 | 2 条 | 宁少勿滥，一般只降不升 |
| Y2 多天无回应 | ≥2 天 | 可按行业周期调整 |
| W2 短对话轮数 | <3 轮 | 可按实际情况调整 |
| 大客户 | 不特殊处理 | 可加"历史成交 Top10 买家升一档" |
