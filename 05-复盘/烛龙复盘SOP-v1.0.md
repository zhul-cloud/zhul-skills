# 烛龙话术复盘 · 三层业务改进 SOP v1.0

> **适用范围**：外贸销售团队 / 阿里国际站 + WhatsApp / 聚焦新客对话
> **生效日期**：2026-08-07
> **版本**：v1.0（手动阶段）

---

## 核心原则

1. **业务员自驱**：烛龙复盘报告替代主管的专业判断——负责人不需要懂销售，只需要看分数
2. **宁少勿滥**：每次只复盘 1-2 条对话，只改 1 个行为；看了 20 条但没有行动 = 没有复盘
3. **今天的对话今天改**：当天收到的改进话术，当天发出去，不过夜

---

## 三层结构总览

| 层级 | 执行人 | 频率 | 时长 | 核心产出 |
|------|--------|------|------|---------|
| 第一层：每日自查 | 各业务员自己 | 每天 | 10 分钟 | 当天发出改进后话术 |
| 第二层：周五共学 | 全团队 | 每周五 | 20 分钟 | 群公告：本周共同改进目标 |
| 第三层：月度模式审查 | 负责人 | 每月底 | 30 分钟 | 下月重点改进方向 × 2 |

## 第一层：每日自查

**执行人**：各业务员自己
**时间**：每天下班前 10 分钟

### 选哪条对话复盘？

🔴 **首选（每天至少复盘 1 条）**
- 今天收到的新客户第一条消息
- 今天发出报价的对话

🟡 **次选（有余力时）**
- 买家回复了但自己感觉没接好的
- 多天无回应、今天准备跟进的

⚪ **跳过（不需要复盘）**
- 常规物流确认 / 已付款客户的例行跟进
- 对话少于 3 轮且内容只是地址 / 单号确认

> 每天最多选 **2 条**，宁可精选 1 条。

### 执行步骤

```
Step 1   复制选定对话 → 粘贴到烛龙话术复盘
Step 2   优先读【第六模块：下一步行动清单】
Step 3   今天能发出去的话术 → 现在发
Step 4   把报告截图保存到对应客户文件夹
         命名格式：日期_客户名_关键词
         示例：20260807_John_首次询盘报价歧义
```

### 判断标准

> 如果看完报告后没有任何一条消息发出去，这次复盘等于没做。

## 第二层：周五共学

**执行人**：全团队
**时间**：每周五下班前 20 分钟
**形式**：微信语音 / 视频 / 现场均可
**主持**：三人轮流，每周换一人

### 会前准备（每人 5 分钟）

从本周保存的复盘报告中，选出 **1 份最有代表性的** 带进来。
> 不要求选最好的——通常选"自己当时最拿不准的那条"更有讨论价值。

### 会议流程

```
0–5 分钟    每人一句话介绍自己带来的对话背景
5–15 分钟   主持人选其中 1 份（选问题最典型的）
            全员一起看：
            → 第三模块（问题诊断）
            → 第五模块（改进话术）
15–20 分钟  讨论出"本周共同改进目标"——只选 1 个
            写到群公告
```

### 群公告模板

```
📌 本周改进目标（生效至下周五）

目标：[一句话描述要改的行为]
示例话术：[可直接复制发给客户的英文]

下周五复盘时验证：大家有没有用上？效果如何？
```

**示例**

```
📌 本周改进目标

目标：每个新客户第一条回复，必须包含 1 个 P 问题

示例话术：
"Quick question — is this for a specific project
or for stock replenishment?"

下周五验证：谁用了？客户怎么反应？
```

## 第三层：月度模式审查

**执行人**：负责人
**时间**：每月最后一个工作日，30 分钟
> 不需要销售经验，只看数字。

### 执行步骤

```
Step 1   收集当月所有复盘报告截图（每人约 15–20 份）
Step 2   只看第五模块的评分表，提取 6 个维度得分
Step 3   填入月度汇总表（见下方）
Step 4   找出哪个维度哪个人持续低分
Step 5   写下月重点改进方向 × 2 → 发群公告
```

### 月度评分汇总表

| 业务员 | 需求挖掘 | 情绪把控 | 推进节奏 | 专业度 | 英文质量 | 追加销售 | 趋势 |
|--------|---------|---------|---------|--------|---------|---------|------|
| 业务员 A | | | | | | | ↗ / → / ↘ |
| 业务员 B | | | | | | | |
| 业务员 C | | | | | | | |
| **团队均值** | | | | | | | |

> **负责人不需要分析原因**——分数低说明什么问题，烛龙报告的第三模块已经写清楚了。
> 拿着低分维度，找该业务员当月对应的复盘报告读第三模块即可。

---

## 启动指南：第一周只做一件事

> 不要同时推三层。先把第一层的习惯建立起来（约 2–3 周），再加第二层。

**第一周唯一目标**

每个业务员每天复盘 **1 条首次询盘对话**，读完第六模块行动清单，把改进话术当天发出去。

| 阶段 | 目标 | 新增内容 |
|------|------|---------|
| 第 1–2 周 | 建立每日自查习惯 | 第一层 |
| 第 3–4 周 | 加入周五共学 | 第二层 |
| 第 5 周起 | 加入月度审查 | 第三层 |

---

## 自动化演进路线（Accio Work）

当手动流程跑稳之后，分三阶段接入自动化：

| 阶段 | 时间 | 状态 | 说明 |
|------|------|------|------|
| 阶段一 | 现在 | ✅ 执行中 | 手动：业务员自选对话 → 粘贴 → 复盘 |
| 阶段二 | 约 3 个月后 | 🔲 计划中 | 半自动：Accio Work 每日拉对话 → 按信号打标 → 推送"今天建议复盘这 2 条" |
| 阶段三 | 约 6 个月后 | 🔲 计划中 | 全自动：🔴 标对话自动进入烛龙复盘 → 报告直推业务员 → 负责人只看月度汇总表 |

> 阶段二是关键跃升：从"靠业务员自己想起来"变成"系统告诉你今天看哪条"，执行率会大幅提升。
